# Recherched component stack

The following directions are now represented by explicit fusion interfaces in the repository:

- persistent episodic and procedural experience memory
- live world-state facts and contradiction detection
- capability-gap tracking
- research finding retention
- hypothesis tracking
- governed tool candidates
- deterministic temporal transition learning
- quantum-inspired candidate ranking and annealing
- provider-neutral evolution contracts already present in the project
- continuous intelligence and closed-loop evolution already present in the project
- persistent anti-repetition progress control
- bounded recovery and evidence-driven completion
- optional external scientific backends through capability probes

## External open-source references

Qiskit Machine Learning: https://github.com/qiskit-community/qiskit-machine-learning
Lava: https://github.com/lava-nc/lava

These are optional research backends, not mandatory runtime dependencies. The
fusion core remains CPU-first so the local machine does not become dependent on
large scientific packages.

## Non-negotiable composition rule

Every layer produces evidence for the next layer. No layer is allowed to
self-promote. The existing evolution gates remain authoritative.
